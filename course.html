Single-file interactive course

Indkøbsvogn is a grocery planner that learns the route through the store.

It keeps the active trip on the phone, syncs durable household data in the background, and quietly updates the item order from completed trips. You do not need to be a programmer to follow the story.

By the end, you should be able to answer practical questions like: “If a user taps this button, which file handles it?” and “What belongs in store.ts versus sync/engine.ts?”

Big picture

If you want to change something, here is the short map.

Think of the codebase as a small set of specialist rooms. The shell decides which room is visible, persistence keeps the notebook safe, sync moves durable data to and from the server, and the learning code updates the route order after checkout.

Screen flow App.tsx decides which screen appears and when a trip starts or ends.
Local storage useAppState.ts and domain/store.ts protect the browser cache.
Sync + learning api/client.ts, sync/engine.ts, and domain/app-state.ts keep the household data and route order moving.
